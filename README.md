# factorioDelorean
A factorio mod that adds the delorean timemachine as a car from Back to the future

![Delorean in game](https://github.com/Danielv123/factorioDelorean/raw/master/ingame%20screenshot.png)

## Releasing

Set the version in `info.json`, commit, and push a matching tag (`git tag v3.0.0 && git push --tags`). CI zips the mod and uploads it to the mod portal with the `FACTORIO_MOD_TOKEN` secret.
